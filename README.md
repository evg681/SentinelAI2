# SentinelAI

SentinelAI is an AI Security Agent platform for enterprise security teams.

## Product

SentinelAI uses AI agents to investigate incidents, analyze cloud and repository activity, identify vulnerabilities, and recommend next steps.

### Agents

- Incident Investigator
- Identity Agent
- Vulnerability Agent
- Compliance Agent

## Repository

- `docs/` — user-facing documentation
- `locales/en/` — product copy and source strings
- `prompts/` — AI-agent instructions
- `api/` — API/error definitions
- `onboarding/` — onboarding content

## Content principles

- Be clear without hiding technical meaning.
- Do not imply that an investigation guarantees that a system is safe.
- Tell users what happened and, when appropriate, what they can do next.
- Preserve placeholders and technical identifiers.
