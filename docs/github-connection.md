# Connect GitHub

Connect GitHub so SentinelAI can investigate your repositories.

## Connect

1. Go to **Settings**.
2. Select **GitHub**.
3. Click **Connect**.
4. Allow access to your repositories.

SentinelAI needs access to your GitHub account to investigate repositories and security issues.

## Permissions

SentinelAI requests repository access.

## Troubleshooting

If GitHub doesn't work, try again.

If the problem continues, contact support.
