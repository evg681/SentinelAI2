# Release Notes-Technical

## August 2026

### Incident Investigator

The new Incident Investigator analyzes data from:

- CloudTrail
- Kubernetes audit logs
- GitHub activity
- CI/CD events

It combines findings from these sources into a single investigation summary.

The agent automatically analyzes available security data and identifies critical issues.

Investigate incidents faster with the new Incident Investigator.
